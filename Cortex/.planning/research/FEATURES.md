# Feature Research Snapshot

## Реально существующие продуктовые возможности

### Event discovery

- Просмотр импортированных событий
- Поиск по событиям
- Фильтрация по категориям
- Переход на карточку отдельного события

### Forecast generation

- Выбор провайдера и модели
- Фильтрация моделей по выбранному провайдеру
- Потоковая генерация прогноза
- Отображение reasoning, confidence и источников
- Сохранение результата в журнал прогнозов

### Accuracy tracking

- Автоматическое обновление resolved outcome
- Расчёт `brier_score` для сохранённых прогнозов
- Leaderboard моделей

### Account and billing logic

- Регистрация и логин
- Профиль пользователя
- План пользователя (`free` / `premium`)
- Daily forecast quota для бесплатного плана
- BYOK-управление провайдерскими ключами

### Admin

- Просмотр пользователей
- Апрув / promote / plan change
- Управление каталогом моделей
- Поиск и импорт событий Polymarket
- Resync/delete/truncate для событий
- DB size и вспомогательные операции
- Дополнительные фильтры по дедлайнам и календарный режим просмотра событий в админке

## Частично решённые зоны

- Whitelist policy есть, но реализована не как жёсткая end-to-end бизнес-граница
- Premium story пока не полностью оформлена на уровне UX и catalog access
- Event curation workflow управляемый, но не автоматизированный
